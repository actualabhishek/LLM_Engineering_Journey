# postflow: Telegram-driven LinkedIn pipeline

A Claude Code plugin. Send a topic on Telegram, and it researches it, drafts a post in a defined voice, generates an image, sends both back for an APPROVE or REJECT reply, and publishes to LinkedIn through Playwright once approved. Posts are tracked in Airtable. Built with Claude Code.

Install, configuration and how approval works are in [postflow-plugin/README.md](postflow-plugin/README.md). The step-by-step pipeline logic is in `postflow-plugin/skills/postflow-pipeline/SKILL.md`.
